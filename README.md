# hukuk_rag_projesi
Bu proje, hukuk alanında benzer karar araştırmasını kolaylaştırmak amacıyla geliştirilmiştir. Metinler embedding vektörlerine dönüştürülmekte, benzerlik hesaplamaları yapılarak kullanıcı olayına en yakın kararlar tespit edilmektedir. Proje; NLP, embedding, similarity search ve retrieval kavramlarını uygulamalı olarak göstermektedir.
